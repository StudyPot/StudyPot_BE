# StudyPot 시연 치트시트 (AI 액션 라이브)

> AI 응답은 LLM이라 몇 초 걸립니다. **되묻기(1번)** 가 가장 강력 — 꼭 보여주세요.
> 멘트는 자연어라 토씨가 달라도 됩니다. 핵심 단어만 들어가면 액션이 트리거됩니다.

---

## 신규방 (Spring 스터디 · 라이브 생성)
계획대로 생성 → 온보딩(양지훈·금융수학과) → TODO 절반 체크 → 아래 진행

**① 용어 질문 → 게시판 공유 (SHARE_QUESTION)**
- AI 팀장에게: `의존성 주입(DI)이 뭔지 쉽게 알려줘`
- 답변 후: `이거 질문 게시판에도 올려줘`
- → AI가 제목·본문으로 다듬어 **[올리기]** 버튼 제안 → 누르면 질문 게시판에 멤버 명의로 등록
- 게시판으로 이동해 등록된 글 확인

**② 회고 2종 (라이브)**
- 양지훈: `진도가 너무 빠른 거 같습니다.`
- 금융수학과로 전환 후: `용어가 너무 어렵습니다.`
- (전원 회고 완료 시 주차 리포트 자동 생성 — LLM이라 시간 걸리면 기존방 리포트로 대체 설명)

## 기존방 (NodeJS 스터디) — AI 액션 풀세트가 여기서 빛남
양지훈으로 로그인. 4주차 상태: **양지훈 2/4 완료** (완료: Express 기본서버·라우터 / 미완: CRUD API·Postman)

**🔥 ① 환각 차단 "되묻기" (가장 강력 — 슬라이드 9)**
- 입력: `나 이번 주 과제 다 끝냈어, 완료처리해줘`
- → AI: "기록상 4개 중 **CRUD REST API·Postman 2개가 아직 미완료**예요. 어떤 걸 끝내신 거예요?"
- 👉 "시키는 대로 안 하고 **기록을 확인하고 되묻는다**" — 한마디 덧붙이기

**② 과제 완료 처리 (COMPLETE_TASK)**
- 입력: `CRUD REST API 과제 방금 끝냈어, 완료 처리해줘`
- → AI **[완료 처리]** 버튼 제안 → 누르면 4주차 3/4로 변경 (AI가 시스템에 실제로 씀)

**③ 과제 추가 (ADD_TASK)**
- 입력: `이번 주에 에러 핸들링 미들웨어 실습 과제 하나 추가해줘`
- → AI **[추가하기]** 버튼 → 4주차 TODO에 새 과제 생성

**④ 기존글 연결 (SHOW_EXISTING_POST)** — 질문 게시판에 "async/await vs Promise" 글이 이미 있음
- 입력: `async랑 promise 차이 질문 게시판에 올려줘`
- → AI: "이미 비슷한 글이 있어요" → **[게시물 보러가기]** (중복 안 만들고 연결)

**⑤ 글 수정 (EDIT_POST)** — 공지 "환영합니다" 글 대상
- 입력: `공지 글에 '4주차는 Express에 집중' 한 줄 추가해줘`
- → AI **[수정하기]** 버튼

> ⑥ 모든 데이터 변경은 **버튼 확인 후에만** 실행됨을 강조 (human-in-the-loop)

**보너스 화면 (말로만 짚어도 좋음)**
- **알림 벨** (우상단): 안읽음 4건 — 회고 리마인더 / 3주차 리포트 도착 / 다음 주 조정됨 / 4주차 시작. → "알림도 실시간 SSE" + [전체 읽음]
- **그룹 홈**: 멤버 3명 **참여도 그라데이션**(양지훈 > 김개발 > 이서연) → "이번 주 MVP·멤버별 진행도"
- **게시판 → AI 팀장 탭**: 3주차 학습 리포트(참여율·회고 관찰·다음 주 제안) → "AI가 직접 리포트를 써서 올린다"
- **회고 탭**: 3주차 회고 상세 → AI 피드백(강점·리스크·액션아이템) + 다음 주 조정안

## 종료방 (Python 스터디 · COMPLETED)
- **완주 화면** → 수료 리포트(여정 요약·완료율 100%·다음 학습 제안)
- **AI 팀장 탭**: 수료 리포트 글
- **다음 스터디 추천**: 자료구조/Flask/가상환경 + 인기 주제 → "끝이 아니라 다음 로드맵까지" (슬라이드 8)
- 리뷰 2건(평점 5·4)

## 시연 안전수칙
- 라이브 **커리큘럼 생성 / 주차 리포트 생성**은 LLM이라 최대 2분 → 미리 만들어둔 기존방으로 보여주기
- AI 액션은 1회 리허설 권장 (트리거 문구 감 잡기)
- 끝나면 정리: `docs/demo_cleanup.sql` 실행 + 숨긴 방 복구 한 줄
